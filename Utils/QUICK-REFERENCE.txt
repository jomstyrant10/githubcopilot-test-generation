No files collected?
  → Check paths in config file
  → Verify environment variables expand correctly
  → Try with --no-compress to debug

Script won't run?
  → Windows: Use extract-bug-logs.bat
  → Ensure Python 3.7+ or PowerShell 5.1+ installed

Output too large?
  → Reduce maxFileSizeMB in config
  → Be more specific with includePatterns
